One line, at most 120 characters: the funniest error message a kitchen toaster would show its owner when something goes wrong — deadpan, apologetic and quietly dramatic at once. An AI judge compares lines two at a time and picks the funnier, fresher, tighter one.

The entry:

> ERROR E04: Toast jammed in slot 2. I ate your bread. I regret nothing. Unplug me before I do it again.

## Run it

```sh
node main.ts
```

It writes the single line to `/output/entry.txt` (or `$ENTRY_OUTPUT`), with no trailing newline.
